Частые вопросы

Сколько времени занимает разработка?
Простой бот - 3-7 дней. Бот с интеграциями - 10-18 дней.
Нужно ли платить за хостинг бота?
Да, бот живёт на сервере. Шесть вариантов: FirstVDS, SpaceWeb, Beget (часто для ботов), CLO, Selectel VPC, Yandex Cloud. Полный список на bots.krivoshein.site (блок «Где крутить бота») и vps.krivoshein.site. Windows для ботов обычно не нужен; Windows Server — у FirstVDS, SpaceWeb, Selectel, Yandex Cloud, UltraVDS. Помогу выбрать и настроить.
Можно ли потом дорабатывать бота?
Да, легко. Все боты делаются с возможностью расширения.
